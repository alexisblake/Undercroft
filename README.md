# Undercroft

A pixel-art roguelite deckbuilder. Descend four floors beneath the city, eight chambers each, and duel your way to the Duke's amulet.

## Play locally
```
python3 -m http.server
```
Then open http://localhost:8000.

## Folders
- `index.html`: the page
- `src/`: game code (data, fights, screens)
- `art/`: every sprite sheet, by character
- `tools/slice_sheet.py`: turns a PixelLab sheet into game-ready animation strips
- `tests/`: automatic checks, run on every push

Art and design by Lexi Blake.
